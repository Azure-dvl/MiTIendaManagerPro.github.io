## Qué incluye la app

- **Ventas** — punto de venta rápido con efectivo y transferencia.
- **Stock e IPV** — informe de ventas y existencias por producto.
- **Almacén** — catálogo con entradas, salidas, traspasos e historial.
- **Caja y cuadre** — cierre de turno con conteo y diferencias.
- **Nómina** — utilidades retenidas, faltantes y declaraciones.
- **Op. del día** — resumen del día en tiempo real.

## Vista previa de la galería

La página incluye una galería de capturas de pantalla. Para añadir fotos, coloca las
imágenes en `assets/` y reemplaza cada bloque `.shot` de `index.html` por:

```html
<img class="shot" src="assets/tu-captura.png" alt="Descripción de la captura" loading="lazy" />
```

## Tecnologías

`index.html` es la página completa.
